Projeto Avaliativo

Web Scraping e Análise de Sentimentos nas Redes Sociais durante as Eleições

Valor: 3,0 pontos Individual ou em Dupla

1. Tema do Projeto

Desenvolver uma aplicação em Python capaz de coletar, organizar e analisar publicações de redes sociais relacionadas às eleições brasileiras utilizando Web Scraping, PLN e Análise de Sentimentos.

Objetivo: identificar manifestações positivas, negativas ou neutras sobre candidatos, partidos ou temas políticos.

2. Objetivos de Aprendizagem

  • Aplicar técnicas de Web Scraping.
  • Utilizar bibliotecas Python para manipulação de dados.
  • Realizar limpeza e pré-processamento textual.
  • Aplicar análise de sentimentos.
  • Gerar gráficos e indicadores.
  • Interpretar resultados de análises reais.

3. Descrição do Problema

O projeto busca compreender a percepção dos usuários das redes sociais sobre candidatos durante o período eleitoral.

Perguntas de Pesquisa

  • Qual candidato apresenta mais menções positivas?
  • Qual candidato recebe mais manifestações negativas?
  • Quais assuntos são mais comentados?
  • Como os sentimentos se distribuem?
  • Existe diferença entre a percepção dos usuários?

5. Tecnologias Obrigatórias

Tecnologia Finalidade
